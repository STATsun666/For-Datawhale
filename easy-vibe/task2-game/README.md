# 霓虹星际战机 · NEON STARFIGHTER

一款基于 Canvas 2D 的网页版纵向射击（飞机大战）小游戏。全部画面与音效均由代码实时绘制、合成，不依赖任何图片或音频素材。

## 玩法

- 驾驶战机在霓虹星域中移动，击落不断来袭的敌机。
- 初始 3 点生命；被敌机撞到、或让敌机飞出屏幕底部都会损失 1 点生命。
- 分数每累计 1000 分进入下一波，敌机刷新更快、下落速度更高。
- 击毁重型敌机有概率掉落道具：
  - 三向散弹：持续 8 秒的扇形三连发
  - 修复：恢复 1 点生命
- 最高分通过 `localStorage` 自动保存，刷新页面不丢失。

### 敌机类型

| 类型 | 外观 | 生命 | 分数 | 特点 |
| --- | --- | --- | --- | --- |
| 侦察机 scout | 粉色 | 1 | 100 | 左右摆动前进 |
| 突袭机 dart | 黄色 | 1 | 200 | 速度快、走直线 |
| 重型机 heavy | 紫色 | 3 | 350 | 移动慢、有血条、会掉落道具 |

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动战机 |
| `空格` | 发射激光 |
| `P` / `Esc` | 暂停 / 继续 |
| `Enter` | 开始游戏 / 结束后快速重开 |

自动连发默认开启，可在 HUD 中切换；右上角按钮可开关音效。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev      # 启动开发服务器
npm run build    # 构建到 dist/
npm run preview  # 本地预览构建产物
```

## 技术栈

- Vite 6（开发与构建）
- 原生 JavaScript（ES Modules），无框架
- Canvas 2D 绘制画面，`requestAnimationFrame` 驱动主循环
- Web Audio API 实时合成音效
- localStorage 保存最高分

## 目录结构

```
.
├── index.html      # 页面结构、HUD、开始/结束/暂停界面
├── src
│   ├── main.js     # 入口：收集 DOM、装配各模块
│   ├── game.js     # 游戏主循环、状态机、生成器、碰撞、渲染
│   ├── entities.js # 玩家、子弹、敌机、道具、爆炸粒子
│   ├── input.js    # 键盘输入映射
│   ├── audio.js    # Web Audio 音效合成
│   └── style.css   # 霓虹风格 UI 样式
├── package.json
└── vite.config.js  # 可选，默认无需配置
```
